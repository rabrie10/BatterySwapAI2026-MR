# Historical baseline implementations

This package preserves earlier Cox proportional hazards and discrete-time risk forecasting work. It supports historical artifact loading and regression comparisons.

The default submission uses [`bsai/`](../bsai/) for forecasting and [`batteryswap_solution/`](../batteryswap_solution/) for planning. Start with the [current architecture](../docs/ARCHITECTURE.md) and [reproducibility guide](../docs/REPRODUCIBILITY.md) before running older training scripts here.
