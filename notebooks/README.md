# Exploratory notebooks

These notebooks preserve the early exploration and baseline modeling sequence:

1. `01_eda.ipynb`: exploratory data analysis.
2. `02_feature_engineering.ipynb`: early feature engineering.
3. `03_survival_modeling.ipynb`: survival-model experiments.
4. `04_evaluation.ipynb`: early evaluation workspace.

They are historical research artifacts and may be incomplete or depend on local data. The reproducible current workflow uses [`tools/train_wiener.py`](../tools/train_wiener.py) and [`tools/validate_v6.py`](../tools/validate_v6.py). Start with the [case study](../docs/CASE_STUDY.md) for the final system design.
